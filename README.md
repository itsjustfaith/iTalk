Authentication: Clerk authentication with backend route protection.



Real-time messaging: Socket.IO for live message delivery.



Backend API: Express routes and controllers for users, conversations, and messages.



Database: MongoDB and Mongoose for user profiles and persistent message storage.



Media uploads: ImageKit integration for image and video sharing.



State management: Zustand for managing chat state, selected conversations, messages, and loading states.


Frontend: React, Vite, Tailwind CSS, and HeroUI for the application interface.



User experience: Conversation sidebar, message history, loading feedback, toast notifications, and responsive chat UI.



Security and configuration: Environment variables, protected endpoints, and verified Clerk webhook events.
